Frequently Asked Questions (FAQ)

How do I restore my "Remove Ads" purchase?
Tap the vault icon in the top bar, then "Restore Purchases". As long as you're signed in with the same Apple/Google ID used for the purchase, your ad-free status restores instantly for free.
Why can I only play the Daily Challenge once a day?
Everyone gets the same code each day, and one attempt each - that's what makes it a genuine daily challenge you can compare with friends. Want to play more? Switch to Practice for unlimited random codes any time.
I missed a day - is my streak gone?
Yes - the streak only continues if you crack the code on consecutive days. A missed or failed day resets it, so the next win starts a fresh streak of 1.
Does sharing my result give away the answer?
No - the shared grid only shows how many guesses you used and how close each guess was (⬛🟨⬜), never the actual code or which slot each result refers to.
