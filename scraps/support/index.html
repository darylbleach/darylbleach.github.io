Frequently Asked Questions

I selected three ingredients but got a strange recipe.
If we don't have a hand-crafted recipe for your exact combination, Scraps generates a sensible recipe on the fly using each ingredient's known preparation style (e.g. frying mince, slicing bread). It's designed to always be edible, if a little improvised!
How do I restore my Premium Recipe Expansion Pack?
Open the Store from the ingredients screen and tap "Restore Purchases". As long as you're signed in with the same Apple/Google ID used originally, it will restore for free.
Can I add an ingredient that isn't on the grid?
Yes - use the "Add Custom Ingredient" search box above the grid to add anything not already listed.
Why does Scraps use British terms like courgette and frying pan?
Scraps is written specifically for the UK market, so recipes use British ingredient names and cooking terminology throughout.
