Frequently Asked Questions

Is every level guaranteed to be solvable?
Yes - every level is generated using an algorithm that guarantees a valid solution exists, so if you're stuck, there is always a way through with the pieces provided.
How do I restore "Remove Ads"?
Open the in-game Menu and tap "Restore Purchases". As long as you're signed in with the same Apple/Google ID used originally, it will restore instantly for free.
How do I reset a level I've made a mistake on?
Open the in-game Menu and use the "Restart Game" option to reset your current level back to its starting arrangement.
